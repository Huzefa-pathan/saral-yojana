Project Name: Saral Yojana – Maharashtra Government Schemes (Visual, Professional, RSS-Based)

Build a complete, visually impressive, modern, professional website using:
- Vite + React (frontend)
- TailwindCSS (styling)
- Lovable Cloud Functions (backend)
- MongoDB (database for storing schemes)
- Cron job for auto-updating schemes every 2 hours
- RSS feed parsing (no Supabase, no external APIs)

The website purpose:
Display Maharashtra government schemes, especially farmer and public welfare schemes, by auto-fetching RSS feeds from official sources.  
The UI must be visually appealing, with images, backgrounds, illustrations, and a modern hero layout.

====================================
  BACKEND REQUIREMENTS (NO SUPABASE)
====================================

Use Lovable Cloud Functions ONLY.

Backend features:

1. RSS Fetch Function
Fetch the following feeds:
- https://www.india.gov.in/rss/schemes.xml
- https://pib.gov.in/RssFeed.aspx?ModId=6&Category=agriculture
- https://www.mygov.in/feeds/schemes.xml

2. Parse XML → JSON using rss-parser.

3. Scoring Logic
Each RSS item gets a relevance score:
+5  if contains “Maharashtra”
+4  if contains any district name
+3  if contains “farmer”, “agriculture”, “crop”
+2  if feed source is PIB agriculture

Store items ONLY if score ≥ 5.

4. Storage
Use MongoDB Atlas (free tier) as database.
Store:
{
  title,
  description,
  link,
  publishedDate,
  source,
  relevanceScore,
  districtDetected,
  categoryDetected,
  fetchedAt
}

5. Schemes API Function
Create a cloud function accessible at:
/api/schemes

Supports:
- district filter (?district=)
- category filter (?category=)
- search (?q=)
- pagination (?page=&size=)
- sort by latest

6. Cron Job
Run the RSS fetch function every 2 hours.
After generating the data, save it into MongoDB.
